# StreamRec Cloud — удалённый доступ со сквозным шифрованием (Timeweb Cloud App Platform)

Этот каталог — отдельный репозиторий для GitHub. Записи и файлы остаются на ПК.
Облако пересылает только зашифрованные данные: прочитать их не может ни сервис, ни администратор хостинга.

## Файлы репозитория (в корне)

```
Dockerfile          сборка контейнера (Python 3.12, без root)
.dockerignore  .gitignore
requirements.txt    aiohttp
wheels/             библиотеки для сборки без интернета (pypi.org не нужен)
relay.py            посредник (пересылает шифротекст, проверяет вход)
sync_web.py         обновление интерфейса из основной папки StreamRec
web/                интерфейс: index.html, app.js, app.css, vendor/hls.min.js,
                    e2e.js (шифрование), sw.js (шифрующий service worker), boot.js,
                    login.html, login.js, login.css
```

## Развёртывание

1. На ПК: Настройки → «Удалённый доступ через облако»:
   «Создать» токен → «Сохранить настройки» → введите пароль → «Задать пароль» (появится AUTH_VERIFIER).
2. Приватный репозиторий GitHub → загрузите в корень содержимое папки `cloud`.
3. Timeweb Cloud → App Platform → создать → Dockerfile → репозиторий. «Путь к директории проекта» — пусто, если Dockerfile в корне репозитория (или `cloud`, если загрузили папкой). Проверка состояния `/healthz`.
4. Переменные: `AGENT_TOKEN`, `AUTH_VERIFIER`; по желанию `TOTP_SECRET`, `SESSION_HOURS`. (`E2E_SALT` больше не нужен — удалите, если был.)
5. Деплой → адрес приложения (https://…) вставьте на ПК в «Адрес облака», включите доступ, сохраните.
   Статус на ПК: «Подключено · шифрование включено · пароль и код облака совпадают ✓».

## Смена пароля

ПК → «Задать пароль» с новым паролем → замените `AUTH_VERIFIER` в Timeweb → перезапуск.
Все устройства выйдут, старый ключ перестанет работать.

## После обновления StreamRec

`python sync_web.py` → commit → push. Иначе проверка на ПК покажет «код облака отличается от эталона».
